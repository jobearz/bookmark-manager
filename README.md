### Bookmark Manager (Working Title)

## Planned Features
* **Authentication** 
Email / Password sign-up and login
* **Link Management**
CRUD (Create, Read, Update, Delete) URLs
* **Organization**
Custom text categories / folders 
* **Notes**
Plain-text / Markdown notes per link
* **Search & Filter**
Filter by category 
* **Sharing**
Private personal dashboard only


## Tech Stack
* **Frontend:** **HTMX**
* **Backend:** **Golang**
* **Database:** **PostgreSQL**
